## Projects

### AI-Powered Chatbot for Historical Insights & Air Quality Predictions

**Problem:** Understanding long-term air-quality trends and forecasting future pollutant levels requires combining historical data analysis with predictive modelling.

**Approach:** Built a hybrid Prophet-LSTM forecasting pipeline and an LLM-powered chatbot capable of retrieving historical insights, executing analysis, and dynamically generating visualisations.

**Stack:** Python · Prophet · LSTM · LangGraph · Pandas · CPCB Data

[GitHub](https://github.com/Lucky-Joy/Chatbot-for-historical-insights-and-air-quality-predictions)

---

### Small Grain Classification & Grading Using Deep Learning

**Problem:** Identifying grain varieties and assessing their quality manually can be time-consuming and subjective.

**Approach:** Built a computer-vision system that combines deep-learning-based grain classification with automated quality grading and real-time inference.

**Stack:** Python · TensorFlow · Keras · EfficientNet · Computer Vision · Streamlit

[GitHub](https://github.com/Lucky-Joy/Small-Grain-Classification-and-Grading)

---

### AI Knowledge Chatbot for Banking Operations

**Problem:** Banking operations teams often need to retrieve accurate information from policies, SOPs, and compliance documents quickly.

**Approach:** Built a RAG-based internal chatbot with document retrieval, confidence scoring, source citations, and SME escalation to make responses more reliable.

**Stack:** Python · RAG · Groq · ChromaDB · Gradio

[GitHub](https://github.com/Lucky-Joy)

### CampusAssist

### Dynamic Parking Price Prediction Using Streaming ML
